A two-line robot confession: one sentence owning a specific mistake, one naming the lesson and the fix. The program writes the apology to `entry.txt`.

> I'm sorry I put your passport in the washing machine with your jeans.
> I check every pocket twice now, and the passport stays in the drawer.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
